## If You Get Stuck

### Can't Find the-merger Branch?

```bash
cd /path/to/thecubiqo
git branch -a
# Should see: * the-merger
```

If you don't see it:
```bash
git fetch --all
git checkout the-merger
```

### Push Permission Error?

Make sure you're logged into GitHub with correct credentials.

```bash
# Check your Git config
git config user.name
git config user.email

# If wrong, update:
git config user.name "Your Name"
git config user.email "your@email.com"
```

### Build Fails?

It shouldn't! The build already passed locally.

But if it does in Vercel:
1. Check Vercel logs
2. Verify environment variables are set
3. Ask me for help!
