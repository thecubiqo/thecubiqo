IMPLEMENTED ROUTES (6 NEW)
================================================================================

1. GET /api/admin/usage
   → Token usage stats by agent
   → Returns: totalTokens (input/output), totalCost, byAgent[], totalSessions

2. GET /api/admin/costs  
   → Cost breakdown by agent and model
   → Returns: total, byAgent[], byModel[], totalSessions (with percentages)

3. GET /api/admin/users
   → User management
   → Returns: users[], total (from profiles table)

4. GET /api/admin/config
   → System configuration getter
   → Returns: featureFlags[], environment{}, system{}

5. POST /api/admin/config
   → System configuration updater  
   → Body: { featureFlags: [...] }
   → Returns: success, config{}

6. GET /api/admin/logs?limit=50&offset=0&level=error
   → System logs with pagination
   → Returns: logs[], total, limit, offset, source

7. GET /api/admin/health
   → Health check all services
   → Returns: status (healthy/degraded/unhealthy), services{}
   → Services: supabase, agents, memory, uptime
