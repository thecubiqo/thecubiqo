8. True BYO & Local Computing

Tela's Word

Zero-Retention Paranoia

The user must have absolute confidence that CubiQo is not stealing their data. They must be able to use their own models (Llama 3, Mistral) and run semantic searches completely offline.

MO's Word

Fix The Liability First

Currently, marketing says "Zero Retention", but the database literally stores conversations in Supabase to make the Memory feature work. This is a severe GDPR exposure. We must update the Privacy Policy to state "Consent-Based Retention" and add an explicit "Delete All My Data" button.

AG's Advice

The True Offline Desktop Engine

To achieve true offline BYO, the web architecture is structurally inadequate. In Phase 2, we must wrap Next.js into a Tauri/Electron desktop container. We embed llama.cpp node bindings to leverage local GPUs, and utilize a local ChromaDB/SQLite store for semantic vision/file indexing without sending one byte to the cloud.
