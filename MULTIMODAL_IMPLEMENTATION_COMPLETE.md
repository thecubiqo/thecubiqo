## Architecture

```
User Interface
    ↓
MultimodalToggle (ON/OFF button)
    ↓
useMultimodalAI Hook
    ↓
MultimodalCoordinator
    ├── CameraService → Vision Processing
    └── AudioService → Audio Processing
    ↓
Combined Context
    ↓
Enhanced AI Prompts
```
