CubiQo / The RGY Theory

Everything RGY

The RGY layer helps CubiQo understand what a user wants, catch the keyword, and let the user confirm intent before match or discovery. This version updates the capsule contract to exactly three fields.

Core Capsule Contract

color | keyword | intent
Field 1
Color

Green, Yellow, or Red context.

Field 2
Keyword

The thing CubiQo caught from chat, profile, journal, or onboarding.

Field 3
Intent

Socialize, Collaborate, Trade, pending, suggested, confirmed, or not selected.

Red is already the restricted/adult signal.

There is no extra visible warning field in the capsule. The color itself tells CubiQo which handling mode applies.

Color Zones

Green

Growth, work, wellness, learning, job search, yoga, healthy habits, and goal-oriented help.

Yellow

Casual social life, company, travel, movies, coffee chat, hangouts, comfort, and low-pressure discovery.

Red

Adult-gated, explicit, or restricted contexts where CubiQo asks and confirms before using sensitive profile data.

Keyword First

Keywords should appear when CubiQo catches them, even when intent is unclear. The intent can be selected by the user, suggested by CubiQo, or left blank.

Example
Job Need

Profile says the user needs work; CubiQo can suggest hiring matches.

Example
Travel Company

Profile says the user likes easy company; CubiQo can suggest compatible hangouts.

Example
Adult Dating

CubiQo asks before using adult preferences or opening match surfaces.

Intent Layer

Socialize

Company, hangout, conversation, companionship, events, and casual plans.

Collaborate

Build, learn, practice, improve, plan, study, or work together.

Trade

Exchange money, services, goods, tickets, skills, favors, or marketplace value.

SIGNAL Product Flow

CubiQo routes from private understanding to useful match surfaces: CubiQo CTA → three widgets → keyword room → AI chat → recommendation.

CQ-to-CQ

Private chat between known friends/contacts.

SIGNAL network

Intelligent match/chat across CubiQo users and posts.

Approved connectors

External APIs or services only where permission and policy allow.

Database Needs

profile_memory

User-editable likes, dislikes, wants, needs, preferences, and summaries.

rgy_capsules

Minimum fields: user_id, color, keyword, intent, confidence, display state.

signal_posts

What the user opts into making discoverable.

audit_events

User confirmations, edits, deletes, gates, and connector permissions.

Operating Rules

RGY does

Classifies context, displays keywords, lets users confirm intent, and routes to private chat, SIGNAL match, or approved connectors.

RGY does not

Choose models by color, silently use sensitive preferences, or require any extra visible capsule field beyond color, keyword, and intent.
