Guardrails and Hardcoded Policy

  • Permanent hard stop: no payment/billing/checkout actions.
  • Permanent hard stop: no autonomous final submit, publish, send, push, deploy.
  • Final CTA belongs to the user unless an explicit sandbox/POC override is scoped.
  • Connector tokens are server-side only and must not appear in frontend payloads.
  • Anonymous users cannot do user-owned writes.
  • Browser sessions require approval/audit/session integrity.
  • Savings search can compare and suggest, but never checks out, enters payment details, or completes purchase.
  • Recommendation cards require quality gate plus visible commission disclosure.

Verified Missing Layers From Complete Pipeline

  • memory_events table: referenced by background agent code, but no durable table migration exists yet.
  • user_ai_profile table: needed for CubiQo's inferred read of the user; not present yet.
  • Anonymous memory layer: no complete localStorage TTL, 72-hour loss-aversion trigger, or signup migration path yet.
  • Session boundary: no durable "30 minutes inactive = close session and summarize memory" loop yet.
  • Journal to memory: journal_entries exists, but extraction into memory_events/user profile is not complete.
  • Perception routes: text exists; browser SpeechRecognition exists in frontend; image/browser screenshot to Vision is not unified into one normalised input pipeline.
  • Voice output: TTS route exists; greeting endpoint and response-length voice gate still need to be built.
  • Savings-first recommendation engine: recommendation tables, quality gate, coupon/rate search, card UI, and redirect tracking are not built yet.

Correction To Earlier Missing Claim

Safety patterns are not merely theoretical anymore. The classifier imports safety-pattern-cache and calls getSafetyPatterns with a Supabase client. The remaining work is operational verification and admin UX, not first wiring.

Savings-First Monetization Plan

  • Subscription checkout is intentionally deprioritized because CubiQo is too early to ask users to pay directly.
  • The near-term wedge is: compare options, find better rates, find coupons, explain why, then attach a transparent recommendation card.
  • Tier 1 direct partners come first: Shopify, Printify, Canva, Fiverr, Webflow, Squarespace, Typeform, Zapier, Notion, Coursera, Udemy, HubSpot, Calendly, Mailchimp/Klaviyo.
  • Skimlinks and Amazon PA API wait until the quality gate, tracking, dashboard, and consent layer are stable.
  • Browser extension attribution is much later, if ever, because it is trust-sensitive.

Revenue Tracking and Admin Metrics

  • Track shown, clicked, saved, dismissed, already-have-this, compare requested, cheaper option found, coupon found, conversion reported, and postback conversion.
  • Admin dashboard should show CTR, save rate, conversion rate, revenue per active user, API cost per active user, gross margin, top partners, and bad recommendation reports.
  • API targets: /api/affiliate/[tracking_id], /api/recommendations/evaluate, /api/recommendations/savings-search, /api/recommendations/feedback, /api/admin/affiliate.
