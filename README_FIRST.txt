================================================================================
                        💡 KEY CONCEPTS (SIMPLIFIED)
================================================================================

GIT:
  Version control system (like "Track Changes" in Word, but for code)
  Saves history of all changes
  Lets multiple people work together

BRANCHES:
  Different versions of your code
  Like parallel universes
  Can switch between them easily

GITHUB:
  Cloud storage for Git repositories
  Like Dropbox for code
  Free for public projects

VERCEL:
  Hosting platform for websites
  Automatically builds and deploys
  Provides URLs for testing

SUPABASE:
  Database + authentication service
  Stores user data, chats, etc.
  Handles user login/signup

NEXT.JS:
  Framework for building websites
  Makes React easier to use
  Handles routing, building, etc.
